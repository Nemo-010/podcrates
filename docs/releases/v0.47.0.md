# podcrates v0.47.0

The forty-seventh release of podcrates. It carries three new meeting
points of the pairing by a code for podssh (Nostr, WebTorrent's trackers,
ntfy; PodUtils/podssh#235, #237), a client of `pod-devtunnel` with no user
token, the `close` of the HTTP road, the options of RFC 8489 and RFC 8656
in `pod-turn`, the stand-in of the S3 API for podnet
(PodUtils/podnet#564), and the next command of a Windows guest on a new
mailbox medium for podvm.

## How a consumer takes it

Each podcrates dependency names the tag `v0.47.0`.

- podssh: fill `Ends::ntfy`, `Ends::relays` and `Ends::trackers` from
  `pod_services::of_kind("ntfy-server")`, `("nostr-relay")` and
  `("webtorrent-tracker")` in rank order, each with a switch that empties
  it; set `Ends::upgrade_refused` from your probe; show the events
  `relay.code.{ntfy, nostr, tracker}` as the line of the third party
  (PodUtils/podssh#235, #237). `pod-devtunnel`: `AccessToken::new` or
  `Credential::Anonymous` where a user has no token.
- podnet: remove your copy of the S3 stand-in; take `pod-link` with the
  feature `s3-standin` as a dev-dependency (`StandIn::start_thread`,
  `url()`, `counts().refused`).
- podvm: `Options::mailbox = MailboxBus::Usb` and `swap::Swap::next` for
  the next command of a Windows guest; the root disk boots after a boot
  medium.

## Breaking

- `pod-relay`: `Ends` has the fields `ntfy`, `relays`, `trackers`,
  `upgrade_refused` and `pace`. A struct literal names them.
- `pod-devtunnel`: `Management::connect_info(&Credential)`;
  `ConnectInfo::token()` gives an `Option`.
- `pod-turn`: `Transport::Tls { alpn }`; `Settings::allocation`.
- `pod-guest`: `Options::mailbox`; the argv of a plan with a boot medium
  gives the root disk `bootindex=1`.

## Known defect

- `pod-guest`: the next command of a Windows guest is proved up to the
  first command on a real guest; the swap is proved by the stand-in and
  QEMU with no guest (T-602, partial); the warm restore gives the next
  command on the saved mailbox (T-628, open); the QMP commands name the
  drive by the deprecated `device` (T-632, open).
- `pod-turn`: the check of a SHA-256 answer has no server of another party
  (T-631, open).
- `pod-netlab`: five value sets of sand-net have no source (T-586,
  partial).
- `pod-gsr` on Windows ARM64: `STATUS_ACCESS_VIOLATION` (T-131, open).
