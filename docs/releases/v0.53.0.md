# podcrates v0.53.0

The fifty-third release of podcrates. It carries the fixes of
PodUtils/podssh#262 and the ask of PodUtils/podvm#414.

## Crates

| Crate | Change | Consumers |
| --- | --- | --- |
| `pod-ws` | The pooled HTTP/2 connections have numbers; `h2_road::Links` and `h2_road::connect_link`: a link that replaces another takes only a newer connection, or opens one (T-686, call C666). A CONNECT with no answer within `ANSWER_WAIT` pings its connection; a connection that gives no answer to the ping within `PING_WAIT` leaves the pool, and the link tries once on a new one (T-687, call C667) | podssh |
| `pod-relay` | The resumable layer: a spare and a resume after a loss ride a new HTTP/2 connection, not the silent one (`Context::for_one_session`); the session in the test resumes about 3 s after the link returns (T-686, PodUtils/podssh#262) | podssh |
| `pod-enter` | The namespace rung through a user namespace binds the host's `/dev/null`, `/dev/zero`, `/dev/full`, `/dev/random`, `/dev/urandom` and `/dev/tty` onto the image's, over a regular file, a missing path or a character device, never over a link or a directory; `nosuid` and `noexec` on each bind (steps 30 to 32; T-688, PodUtils/podvm#414; calls C668 to C670) | podvm |
| `pod-services` | `node-trojan-149-28-130-108` leaves: its TLS handshake failed on two runs (T-684); the `node-*` files are 7 | podssh |
| `pod-extract` | Tests only: the plants of T-597 and T-598 catch again (T-678, call C646) | |

## How a consumer takes it

Each podcrates dependency names the tag `v0.53.0`.

- podssh: the bump of the tag. The resumable layer takes the fix of
  PodUtils/podssh#262 with no change of its glue (one `Dialer` for each
  session). `node-trojan-149-28-130-108` leaves the list of node ids
  (PodUtils/podssh@T-574).
- podvm: the bump of the tag; the namespace rung through a user
  namespace now has the device nodes of the host (PodUtils/podvm@T-1912).
- podnet, podrunner: the bump of the tag.

## Breaking

None for an existing call. `pod_ws::h2_road` has new items (`Links`,
`connect_link`, `ANSWER_WAIT`, `PING_WAIT`).

## Known defect

- Two plants depend on the runner: `enter-userns-proc-no-remount`
  (T-689) and `link-arq-vectored-first-only` (T-557).
- `pod-egress`: a failed TLS handshake or upgrade on VLESS, VMess and
  Trojan is `WebSocket`/`Unavailable` (T-652, open).
- `pod-gsr` on Windows ARM64: `STATUS_ACCESS_VIOLATION` (T-131, open).

## Publish

`publish.yml` runs on the tag: the dry run of `cargo publish --workspace`.
The switch `crates-io` of `Cargo.toml` is false (the owner, 2026-11-09).
