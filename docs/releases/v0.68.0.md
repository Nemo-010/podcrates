# podcrates v0.68.0

The sixty-eighth release of podcrates. It carries five asks of podssh
(new roots and one rsa, a route to a Unix socket on Windows, a relay's
liveness offer, the headers of Cloudflare Access, the two speeds
explained), one of podvm (the source fixup
reads no comment), the import of `pod-cloudflare` from podnet, the
device-code logins of `pod-devtunnel`, and more parts of the findings of
the ingest study.

## Crates

| Crate | Change | Consumers |
| --- | --- | --- |
| `pod-relay` | A relay's liveness offer (`liveness` `{"frame":"ws-ping","pingMs":N}`): the node reads it from `hello`, the operator from `ready`, and each starts its watch of Pongs again at that pace (30 to 60 s taken, over 60 s held to 60 s, under 30 s not taken). `forward_layer::offer::Offer.liveness` keeps `forward.liveness`. `pod_relay::liveness` (`pace`, `pace_in`, `VECTORS`: the 12 vectors of podssh's document) (T-845, PodUtils/podssh#300) | podssh, podnet |
| `pod-relay` | `Handler::liveness(pace)` at each `hello`; `Layered` opens each new session with no heartbeat while an offer holds, so an idle link carries no frame of the layer (T-845) | podssh, podnet |
| `pod-session` | `Settings.heartbeat` (default `true`), `Settings::quiet()`, `Settings::names()`, `HEARTBEAT`: an end that leaves `heartbeat.v1` out ends the heartbeat of both (T-845) | podssh, podnet |
| `pod-ws`, `pod-relay`, `pod-egress` | The headers of the caller for a host on each road (`pod_ws::Headers` in `Way::with_headers`, values in `Zeroizing`), after `X-Relay-Token`: the upgrade over TLS, HTTP/2, the HTTP road, QUIC, the reverse road, the URL road and the forwarder. A name that is not a token or that a road writes itself, and a value with a control character, are refused before a byte goes out, by the name alone; a value is masked in the words of a refusal, and a 401 or 403 keeps its status. A road in cleartext writes them only with `Headers::in_cleartext(true)` (C775) (T-847, PodUtils/podssh#302) | podssh |
| `pod-relay` | A route to a Unix socket on Windows (`unix:PATH`), by WinSock `AF_UNIX`; one `unix_target::connect` for both families (T-844, PodUtils/podssh#298) | podssh |
| `pod-tls` | webpki-roots 1.0.12 (`ROOTS_PUBLISHED` 2026-11-10; T-840), and rsa 0.10 with sha2 0.11, so a consumer has one rsa (T-841, PodUtils/podssh#297) | each project |
| `pod-ws` | A dial that offered a subprotocol refuses an answer that names another one (`client::upgrade`; T-385) | each project |
| `pod-devtunnel` | The device-code logins of GitHub and Entra ID, the refresh of an Entra token, and the store of the user's token in a private file (`login`, `store`; T-378) | podnet |
| `pod-cloudflare` | New crate, from podnet: the edge client, the named tunnel and the quick tunnel; typed failures, events for each line for the user, the words of the consumer as settings, `noTLSVerify` through the consumer's configuration, its fuzz targets and plants (T-029, partial) | podnet |
| `pod-rootfs` | The source fixup reads a URL only on a line that the package manager reads: no comment line, and in a `*.sources` file only the field `URIs` (T-846, PodUtils/podvm#463) | podvm, podrunner |
| `pod-netstack` | `mss::clamp_mss`: the MSS of a SYN held to the MTU of a path, with the checksum of RFC 1624; `class`: the class of a flow by a rule, its DSCP or what the table saw (T-819, part) | podnet |
| `pod-core` | `pick`: a sticky choice by weighted rendezvous hashing with tiers, over SipHash-2-4 (T-823, part) | podssh, podnet |

## Tests and checks

- `pod-relay`: `tests/liveness_offer.rs` (paused time: the first Ping at the offered pace; the handler hears the pace) and the vectors of podssh's document.
- `pod-session`: `a_quiet_far_end_ends_the_heartbeat_of_both_sides` (200 s idle, no `PING` either way).
- `pod-ws`, `pod-relay`: `tests/caller_headers.rs` (each road reads the headers after the token; the refusals; the mask; cleartext only where allowed).
- `pod-rootfs`: the `ubuntu.sources` of 24.04: no probe of the host of its comment.
- `pod-netstack`: the incremental checksum against a full sum for each word, and the ladder of the path MTU; `pod-core`: the vectors of the SipHash paper, and 8 threads that never overspend a quota.
- `static-probe` links `pod-cloudflare`.
- New plants: `relay-node-ignores-the-liveness-offer`, `relay-node-keeps-the-heartbeat-under-an-offer`, `session-quiet-still-names-the-heartbeat`, `rootfs-source-comment-read`, `netstack-mss-checksum-word-aligned`, `netstack-flow-key-without-ports`, `core-pick-without-weight`, `core-quota-counts-after-the-write`, `netstack-pmtu-probes-for-ever`, `ws-chosen-protocol-unchecked`, `ws-caller-headers-not-sent`, `devtunnel-store-others-read`, and the plants of `pod-cloudflare`.

## How a consumer takes it

Each podcrates dependency names the tag `v0.68.0`; `issue-sync.yml@v0.68.0` takes `podcrates_ref: v0.68.0`.

- Each: `cargo update -p webpki-roots` (podnet's and podssh's tests hold their lock to `ROOTS_VERSION`), and a russh that takes rsa 0.10.0, not a release candidate (podssh: 0.65.2).
- podssh: the liveness offer is in the node and the operator with no change. On the forward road, take `Offer.liveness` into `spawn_paced`, and set `Settings::quiet()` on the layer when it holds. The wire is `pingMs`, as podssh's reference; the issue's text said `every_s`.
- podssh: a route `unix:PATH` works on Windows too.
- podssh: give the credentials of Access with `Way::with_headers(Headers::new(...))`, for the hosts that the user named; a road in cleartext needs `Headers::in_cleartext(true)` too.
- podvm and podrunner: the source fixup asks no more about the host of a comment.
- podnet: `pod-cloudflare` waits for its adoption trial (T-029); take it when the trial is green.

## Breaking

- `pod_session::Settings` has a new public field (`heartbeat`); a consumer that builds it with `..Settings::default()` takes it with no change.
- `pod_relay::reverse::Handler` has a new method with a default (`liveness`).
- `pod_ws::Way` has a new public field (`headers`); `Way::new` sets none. `pod_relay::http_road::client::Road` has a new field (`extra`), which `Road::tls` fills.

## Known defect

- `pod-session`: the cause of the stalled resume of PodUtils/podssh#283 is open (T-767, partial); a spare waits 20 s when a full link holds the writer (T-768, open).
- `pod-cloudflare`: the adoption trial of podnet and the rest of T-029 (partial).
- `pod-relay`: the fetches of `/relays.json` send no header of the caller yet, so a relay behind Access gives an empty pool and offer (T-848, open).
- The nightly: armv7 (T-789), riscv64 (T-766).
- `pod-iroh`: the relay dial takes a proxy URL, not the caller's dialer (T-809).
- `pod-gsr` on Windows ARM64: `STATUS_ACCESS_VIOLATION` (T-131, open).
