# podcrates v0.56.0

The fifty-sixth release of podcrates. It carries the kind `reference` of
an issue (PodUtils/podvm#435).

## Crates

| Crate | Change | Consumers |
| --- | --- | --- |
| `pod-todo` | The kind `reference`: an issue that holds no work (a capture or a document that a session uses). The column `Kind` names it, or a title that starts with `[Reference]`. It needs no entry; its entries are notes (T-723) | podvm, each project |

## Scripts and workflows

- `scripts/issue-sync.py`: a reference gets its status block, and the sync never closes or opens it (T-723).

## How a consumer takes it

Each podcrates dependency names the tag `v0.56.0`; the call of
`issue-sync.yml` names `@v0.56.0` and `podcrates_ref: v0.56.0`.

- podvm: name each reference `reference` in the column `Kind` (or keep the
  `[Reference]` title), then turn `issue_rules = "on"`.

## Breaking

None.

## Known defect

As in `v0.55.0`.

## Publish

`publish.yml` runs on the tag: the dry run of `cargo publish --workspace`.
The switch `crates-io` of `Cargo.toml` is false (the owner, 2026-11-09).
