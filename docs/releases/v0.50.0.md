# podcrates v0.50.0

The fiftieth release of podcrates. It carries the first group of the move
of podssh's waves 3 and 4 (PodUtils/podssh#248, the ruling "The move of
podssh"): five new crates from podssh at `b9c04657`.

## Crates

| Crate | Change | Consumers |
| --- | --- | --- |
| `pod-transit` | New. The transit road of magic-wormhole from podssh-relay `transit/` (without `link.rs`): `Config` (the relay, the caller's `pod_ws::Way`, the trust, the bounds, the events), `Dialer`, `carry`, `far::{Node, dial, serve, serve_kept}`, `meet`; typed failures. The variable `PODSSH_TRANSIT` stays in podssh (T-027, calls C598 to C600) | podssh |
| `pod-acme` | New. The ACME client from podssh-cli `acme/`: the account, the order by TLS-ALPN-01, the renewal, the store in the caller's places; HTTPS through the caller's `pod_proxy::Client`; P-256 keys in pure Rust from `pod-core` entropy, and keys that podssh stored with aws-lc-rs still load (T-034, call C601) | podssh |
| `pod-piping` | New. The Piping Server carrier from podssh-relay `piping/`: the paths, the hello and the marks of a pair, the streamed and the numbered link, HTTP/1.1 and HTTP/2, the probe; the caller's `Way` and user agent; the tests against nwtgck's two servers in CI (T-032, call C602) | podssh |
| `pod-opentunnel` | New. The OpenTunnel carrier from podssh-relay `opentunnel/`: the API and its retries, the record of a tunnel in the caller's places, the provision, the node; the caller's `Way`, provider and user agent; fixes of an IPv6 service on port 443 and of the check of a host, found by its fuzz target (T-033, call C603) | podssh |
| `pod-derp` | New. The DERP road from podssh-relay `derp/`: the client, the carrier of a node, the servers, the stand-in behind the feature `standin`; the caller's `Way`, `Names`, events, typed failures; the `AppName` escaped as JSON (T-031, calls C606 to C609) | podssh |

## How a consumer takes it

Each podcrates dependency names the tag `v0.50.0`.

- podssh: apply `adoption/podssh/pod-transit.patch`, then
  `pod-acme.patch` (`pod-acme.needs`), `pod-piping.patch`, then
  `pod-opentunnel.patch` (`pod-opentunnel.needs`), and
  `pod-derp.patch`, each at `b9c04657` (its `.commit`); each `.run` names
  the checks. Each patch moves each podcrates tag to `v0.50.0`; the
  patches touch the same lines of the manifests, so apply them one on
  the other and keep each change. The modules `transit/`, `acme/`,
  `piping/`, `opentunnel/` and `derp/` leave podssh.
- podnet, podvm, podrunner: the bump of the tag only.

## Breaking

None for an existing crate.

## Known defect

- `pod-link`: a closed half of a split session can end the listener with
  "the carrier of the link ended" (T-639, open, PodUtils/podnet#572).
- `pod-guest`: a cold boot of `run` of a Windows guest under KVM can reach
  no shutdown (T-640, open, PodUtils/podvm#380).
- `pod-derp`, `pod-acme`, `pod-opentunnel`: tests against the real derper
  (T-636), a whole order against Pebble (T-637), and the stand-in of
  OpenTunnel as a feature (T-638) are open.
- `pod-netlab`: five value sets of sand-net have no source (T-586,
  partial).
- `pod-gsr` on Windows ARM64: `STATUS_ACCESS_VIOLATION` (T-131, open).

## Publish

The switch `crates-io` of `Cargo.toml` is false (the owner, 2026-11-09).
The owner reserves `pod-actions-store`, `pod-actions-results`, `pod-udf`,
`pod-qga` and the five new names on crates.io before a publish ("Owner
actions" of `TODO/PROGRESS.md`).
