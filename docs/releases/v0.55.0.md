# podcrates v0.55.0

The fifty-fifth release of podcrates. It carries the sync of the issues
against the record (the owner's ruling "Issues") and the host classes of
podssh and podnet as profiles of `pod-lab`.

## Crates

| Crate | Change | Consumers |
| --- | --- | --- |
| `pod-todo` | The kind of each issue (report, coord, request, deferred, tracker, pull; an optional column `Kind`, else from the title). The rules of the state of an issue against its entries, on where `TODO/todo.toml` says `issue_rules = "on"`. `pod-todo issues --block N` and `--json`: the status block of an issue from the record (T-703; calls C692 to C698) | each project |
| `pod-lab` | 18 new profiles from PodUtils/podssh#268 and PodUtils/podnet#585 (34 in all). A lab with no root holds `listen-denied`, `udp-denied`, `raw-denied`, `no-ptmx`, `no-passwd-entry`, `noexec-home`, `no-proc`, `seccomp-nonewprivs`, `no-tun`, `no-net-admin`, `ro-etc-ssl`, `no-loopback`; the six network classes are named and refused until podnet's data (T-716). `LANES.md`: the commands of each project in each profile. `pod_lab::profile::Call` takes conditions on its arguments (`When::Bits`, `When::Equal`) in place of one mask (T-701; calls C699 to C705) | each project |

## Scripts and workflows

- `scripts/issue-sync.py` and `.github/workflows/issue-sync.yml`: the block of each issue, a close or an open again from the record, and a dry run; a project calls the workflow at this tag (`docs/session-protocol.md`, item 5). An issue of an author outside the team with no label `confirmed` is not touched. An unmapped issue younger than 3 days is a note.

## How a consumer takes it

Each podcrates dependency names the tag `v0.55.0`.

- Each project: repair the map of `TODO/issues.md` (PodUtils/podcrates#192), set `issue_rules = "on"` in `TODO/todo.toml`, and call `issue-sync.yml` at `v0.55.0` with `podcrates_ref: v0.55.0`. Run the dry run first.
- Each project: the lanes of `crates/pod-lab/LANES.md` before each release.

## Breaking

- `pod_lab::profile::Call`: a call with a mask names `When::Bits` now.
- `TODO/issues.md`: a tracker needs the column `Kind`.

## Known defect

- `pod-lab`: the probe rows of T-714 to T-716 are open; a check of a report sees those parts as unseen.
- `podlab`: its usage errors come from clap (T-704, open); `check-strings.py` reads ELF only (T-705, open).
- `pod-egress`: a failed TLS handshake or upgrade on VLESS, VMess and Trojan is `WebSocket`/`Unavailable` (T-652, open).
- `pod-gsr` on Windows ARM64: `STATUS_ACCESS_VIOLATION` (T-131, open).

## Publish

`publish.yml` runs on the tag: the dry run of `cargo publish --workspace`.
The switch `crates-io` of `Cargo.toml` is false (the owner, 2026-11-09).
