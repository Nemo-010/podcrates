# podcrates v0.57.0

The fifty-seventh release of podcrates. It fixes the build of `pod-todo`
in the reusable workflow `issue-sync.yml` (PodUtils/podvm#437).

## Workflows

- `issue-sync.yml`: `pod-todo` builds outside the workspace of the caller, so the `.cargo/config.toml` of the caller (a build target, a linker, rustflags) does not reach it (T-724).

## How a consumer takes it

Call `issue-sync.yml@v0.57.0` with `podcrates_ref: v0.57.0`. Each
podcrates dependency can name the tag `v0.57.0`; no crate changed.

## Breaking

None.

## Known defect

As in `v0.55.0`.

## Publish

`publish.yml` runs on the tag: the dry run of `cargo publish --workspace`.
The switch `crates-io` of `Cargo.toml` is false (the owner, 2026-11-09).
