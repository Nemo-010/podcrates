# podcrates v0.69.0

The sixty-ninth release of podcrates. It is the first tag that podnet can
take `pod-cloudflare` from: the crate has the five changes of its API that
podnet's adoption trial needed, and the trial passes. It also carries one
rule of a clean text of a peer, the watches of the pin of cloudflared, and
a gate of no blocking call in a hot path.

## Crates

| Crate | Change | Consumers |
| --- | --- | --- |
| `pod-cloudflare` | The API of podnet's glue (T-029): `Metrics::with_extra` and `TunnelBuilder::metrics` (the consumer gives the counters of a tunnel and adds its own text); `Metrics` is a `pod_ws::Tally`; the stand-in of the service and of the edge is the feature `standin` (`standin::quic::local_pair` for an in-memory QUIC pair); a reset or a close in the TLS handshake is said in the words of `fail::tls_text`; `proxy::path_and_query` is public | podnet |
| `pod-cloudflare` | `tools/check-upstream.py` (the pin of cloudflared against the pinned and the newest release) and `tools/check-header-oracle.sh` (the header encoding against cloudflared's Go code) run each day in `upstream.yml`, the job `cloudflared`; the example `dump_headers` (T-849) | podnet |
| `pod-core` | `text::one_line` and `text::multi_line` take out each escape sequence of a terminal whole: a CSI or an OSC with its parameters, in its 7-bit and 8-bit forms, and another escape with its intermediates; before, the parameters (`[2J`, `]0;title`) stayed as text. `pod_cloudflare::text::clean` is this rule (T-850) | each project |
| `pod-testkit` | `switches::count`: the voluntary switches of context of a scope (Linux), a gate of no blocking call; a seal and an open of `pod-e2e` and a turn of the ARQ of `pod-link` make none (T-838, part) | each project |

## Tests and checks

- `adoption/podnet/pod-cloudflare.*`: podnet `7fe60e0` with the crate, 24 steps (967 tests). `scripts/adoption.sh` points each manifest of the consumer to the tree.
- `fuzz/seeds/capnp_message/pointer_loop`: the pointer loop that podnet's fuzz run planted.
- `pod-core`: `each_escape_sequence_goes_with_its_parameters`; 13 tests of 7 crates now hold the clean text.
- New plants: `testkit-switches-count-nothing`; `fuzz-one-line-escape` made again on the new rule.

## How a consumer takes it

Each podcrates dependency names the tag `v0.69.0`; `issue-sync.yml@v0.69.0` takes `podcrates_ref: v0.69.0`.

- podnet: take `pod-cloudflare` by the patch of the trial (`adoption/podnet/pod-cloudflare.patch`), with each podcrates tag at `v0.69.0`. The README of the crate gives the glue that stays in podnet.
- Each: a text of a peer loses the parameters of an escape sequence; a test that held them (`[2J` after the strip of ESC) holds the clean text now.

## Breaking

- The text of `pod_core::text::one_line` and `multi_line` for an input with an escape sequence.
- `pod-cloudflare`: the stand-in is behind the feature `standin`.

## Known defect

- `pod-session`: the cause of the stalled resume of PodUtils/podssh#283 is open (T-767, partial); a spare waits 20 s when a full link holds the writer (T-768, open).
- `pod-cloudflare`: the comments in ASD-STE100 (T-029, partial); the pin of cloudflared is 2026.10.7, and 2026.11.0 has the same files (T-851).
- The nightly: armv7 (T-789), riscv64 (T-766).
- `pod-iroh`: the relay dial takes a proxy URL, not the caller's dialer (T-809).
- `pod-gsr` on Windows ARM64: `STATUS_ACCESS_VIOLATION` (T-131, open).
