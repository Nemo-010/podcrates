# podcrates v0.45.0

The forty-fifth release of podcrates. It carries two new crates for
podvm's Windows guest (`pod-udf`, `pod-qga`) and the parts of `pod-guest`
that the first version needs (#152), the rest of podvm's QA defects (#151,
#153, #155), a fix of a credential leak in `pod-proxy` (#156), the
back-off of the spare links of `pod-session` for podssh
(PodUtils/podssh#242), podrunner's changes to its two crates
(PodUtils/podrunner#99), and `bind_udp` with port 0 for podnet
(PodUtils/podnet#552).

## Security

- `pod-proxy`: a proxy on a Unix socket written as a URL with a user and
  a password (`socks5h+unix://USER:PASS@x`) parsed, and its label and
  errors showed the password. A Unix path that starts with `//` or holds
  `@` is now a usage error, and a command proxy shows only its first word
  that is not an assignment (T-612, calls C475 to C479; PodUtils/podnet#555).

## How a consumer takes it

Each podcrates dependency names the tag `v0.45.0`.

- podvm: `pod-udf` and `pod-qga` for the Windows guest; the new
  signatures of `pod-guest` below; `check_exec` before a payload, its
  interpreter and a memfd, and `exec_table` in your `NAMES` (T-583);
  coalesce your `--ulimit` entries before the plan (T-584).
- podnet: `bind_udp(0)`; `KeyRefused` on each listener.
- podssh: `spare_links` back on for the tunnels of HTTP; `Road::tls` sets
  `dial_alpn`.
- podrunner: start a new `--cache` directory; `Forge::is_local` for a
  local reference.

## Breaking

- `pod-guest`: `fetch::store(&mut impl Origin, dest, want, ceiling,
  tries)`; `Plan::options`; `Request::mode`; `provision(.., out, &ready,
  wait)`.
- `pod-relay`: `Road` has the field `dial_alpn`. A struct literal names it.
- `pod-proxy`: a Unix proxy path with `//` or `@` is a usage error.
- `pod-enter`: a plan with two limits of one resource is
  `Error::LimitTwice`.
- `pod-oci`: a host outside the grammar is `Refusal::Host`.
- `pod-actions-workflow`: `ErrorKind::UnknownEvent`,
  `ErrorKind::KeyNotTaken`.
- `pod-actions-results`: `Answer::headers`; `Payload::File(file, len)`.
- `pod-extract`: a directory keeps the exact mode of the image (`0555`);
  a caller that writes into the tree after the extraction opens the
  directory itself (`pod-rootfs` does).

## Known defect

- `pod-netlab`: five value sets of sand-net have no source (T-586,
  partial).
- `pod-guest`: the next command of a guest in keep-alive mode is not
  proven on a real guest (T-602); no NTFS or hive writer (T-617,
  blocked).
- `pod-udf`: no test against an image of a real mastering tool (T-601).
- `pod-extract`: a tree deeper than the limit of descriptors (T-615).
- `pod-hostprobe`: the signal constants of mips (T-618).
- `pod-gsr` on Windows ARM64: `STATUS_ACCESS_VIOLATION` (T-131, open).

## Publish

`publish.yml` runs on the tag: the dry run of `cargo publish --workspace`.
The switch `crates-io` of `Cargo.toml` is false (the owner, 2026-11-09).
The owner reserves `pod-actions-store`, `pod-actions-results`, `pod-udf`
and `pod-qga` on crates.io before a publish ("Owner actions" of
